# 📐 ETF三因子模型详解（v7）

---

## 🎯 核心洞察

国家队（中央汇金）增持ETF有**两条独立路径**：

| 路径         | 市场      | 痕迹                   |
| ------------ | --------- | ---------------------- |
| 二级市场买入 | 交易所    | 成交量异常放大         |
| 一级市场申购 | ETF发行方 | 总份额增加（无成交量） |

只靠成交量（量能因子）判断，会漏掉一级市场路径的信号。

**三因子模型** = 量能 × 50% + 方向 × 20% + 份额 × 30%

---

## 📊 因子一：量能概率（权重50%）

### 原理

汇金单次增持几十到上百亿元，每次大操作都会在成交量图表上留下显著痕迹。

### 计算

1. 取过去20个交易日的每日成交量
2. 计算20日平均成交量（ma20）
3. 当日成交量 ÷ ma20 = **倍量（volume_ratio）**

### 倍量 → 量能概率映射

| 倍量范围 | 量能概率 |
| -------- | -------- |
| <0.5x    | 0~5%     |
| 0.5~1.0x | 5~17%    |
| 1.0~1.3x | 17~35%   |
| 1.3~1.5x | 35~55%   |
| 1.5~2.0x | 55~80%   |
| 2.0~3.0x | 80~95%   |
| 3.0~5.0x | 95~98%   |
| >5.0x    | 98~100%  |

### 设计思路

- 基准用20日（约一个月），对近期资金行为最敏感
- 不对称映射：放量段映射更陡（敏感），缩量段映射平缓

---

## 📊 因子二：方向概率（权重20%）

### 原理

汇金操作目的不是赚钱，而是**护盘**。放量时的市场环境决定该放量是不是"护盘行为"。

### 四个维度（权重 40% / 30% / 20% / 10%）

> 实现说明：`dprob()` 的 f1~f4 按 40/30/20/10 加权后，再乘普涨折扣（见下）。下表中的"5日大盘"指沪深300近5个交易日涨跌幅（负值=下跌趋势）。

**维度1：当日行情 + 大盘环境（40%，f1）**

逆市护盘的实现定义为 **ETF当日上涨 + 大盘近5日处于跌势**（而非"当日大盘下跌"）。按代码顺序判定，先命中先生效：

| 条件（依次判定） | f1 |
| --- | --- |
| ETF涨>0.3% 且 5日大盘<-1% | 95 |
| ETF涨>0 且 5日大盘<-0.5% | 85 |
| ETF涨>0 且 5日大盘<0 | 70 |
| 涨跌绝对值≤0.15% 且 5日大盘<-1% | 80 |
| 涨跌绝对值≤0.3% 且 5日大盘<-0.5% | 65 |
| ETF涨>1% 且 倍量>1.5x（放量上涨） | 45 |
| ETF涨>0.5% 且 倍量>1.3x | 50 |
| ETF涨>0（普涨） | 40 |
| ETF跌<-1.5% 且 倍量>2x（放量下跌，恐慌出逃） | 8 |
| ETF跌<-0.5% 且 倍量>1.5x | 15 |
| 其余 | 25 |

**维度2：ETF vs 沪深300 近5日超额（30%，f2）**

> 注意：超额按**近5个交易日**计算（gap = ETF 5日涨跌 − 沪深300 5日涨跌），非文档早期版本所说的当日超额。

| 5日超额 | f2 |
| --- | --- |
| >3% | 95 |
| >2% | 85 |
| >1.2% | 75 |
| >0.6% | 60 |
| >0.2% | 50 |
| -0.2~0.2% | 40 |
| -0.6~-0.2% | 30 |
| ≤-0.6%（跑输大盘） | 15 |

**维度3：前5日大盘走势（20%，f3）**

| 5日大盘 | f3 |
| --- | --- |
| <-4% | 95（护盘需求极强） |
| -4~-3% | 90 |
| -3~-2% | 80 |
| -2~-1% | 70 |
| -1~-0.5% | 55 |
| -0.5~0% | 45 |
| 0~1% | 35 |
| 1~3% | 20 |
| >3%（需求极弱） | 10 |

**维度4：尾盘行为（10%，f4）**

- 目前简化处理为固定 **35 分**（日线数据无法精确区分尾盘），对方向概率的恒定贡献为 35×10% = 3.5 分
- 理想情况下应分析尾盘拉升幅度

### 普涨折扣

当大盘**当日**涨幅较大时，整体方向概率打折（此折扣统一处理普涨降级，f1 内部不再单独扣减）：

- 大盘涨 >2% → 方向概率×0.60
- 大盘涨 1.5-2% → ×0.70
- 大盘涨 1.0-1.5% → ×0.80
- 大盘涨 0.5-1.0% → ×0.90

## 📊 因子三：份额概率（权重30%）

> **v7 数据源升级**：从 push2.eastmoney.com（已挂）切换为 akshare 交易所官方接口，支持完整历史回溯。

### 原理

通过一级市场申购ETF时，不会产生二级市场成交量，但会直接增加ETF总份额。

### 计算

1. 获取目标日与**前一个交易日**的基金总份额（来自 akshare API，只需两日）
2. 计算日份额变化 = 当日份额 - 前日份额
3. 份额变动比 = 日份额变化 ÷ 前日份额 × 100%

> **每只 ETF 使用其自身的份额变化**（`analyze_all` 按代码独立取值）。2026-08 修复过一处历史 bug：份额因子曾误用 `shares_map` 中第一个代码（510300）的份额变化，导致所有 ETF 的份额P 相同、中小盘份额信号被掩盖——事件锚点测试（tests/）发现并验证了该修复。

### 份额变动比 → 份额概率

映射为**连续分段函数**，0% 无变动处为近中性 15 分：

| 份额变动比 | 份额概率 | 解读                       |
| ---------- | -------- | -------------------------- |
| >10%       | 95       | 大规模申购，明确国家队入场 |
| 5~10%      | 80~95    | 较大规模申购               |
| 3~5%       | 65~80    | 中等申购                   |
| 1~3%       | 45~65    | 小幅申购                   |
| 0~1%       | 15~45    | 常规申购/正常波动          |
| -1~0%      | 10~15    | 轻微赎回                   |
| -5~-1%     | 5~10     | 赎回                       |
| <-5%       | 0~5      | 大幅赎回（疑似减持）       |

> 映射以申购方向为主：同等幅度的赎回得分显著低于申购（1% 申购 45 分 vs 1% 赎回 10 分）。这是有意的偏置——模型只识别增持，减持识别见"模型局限性"。

### 实际案例

以华泰柏瑞沪深300ETF（510300）为例：

- 总份额约333亿份（2026-05-12）
- 份额变动2% ≈ 6.7亿份 → 对应约33亿元
- 份额变动5% ≈ 16.7亿份 → 对应约83亿元
- 汇金单次增持通常在几十到上百亿元 → 落在5%-10%区间

## 📈 综合概率与信号解读

```
综合概率 = 量能概率 × 50% + 方向概率 × 20% + 份额概率 × 30%
```

### 信号分级（三级）

| 综合概率 | 级别      | 解释                 |
| -------- | --------- | -------------------- |
| ≥70%     | 🔴 高确信 | 国家队大概率正在增持 |
| 50~70%   | 🟡 中等确信 | 值得关注，等待更多确认 |
| <50%     | ⚪ 无信号 | 正常交易             |

### 二因子退化（份额数据缺失时）

份额数据不可用的日期（如回溯前的历史日、份额盘后 19:00 未发布），综合概率退化为二因子：

```
综合概率 = 量能概率 × 70% + 方向概率 × 30%
```

**⚠️ 二因子与三因子的 cp 不可直接比较**：三因子把量能权重降至 50%、份额取中性 15 分（恒定注入约 4.5 分）；二因子则把量能权重提到 70%。结果是**高量能日三因子得分可能低于二因子**（量能权重削减超过份额注入），同一天在不同数据状态下算出的 cp 不能直接比大小。跨模式比较历史信号时应加标注（报告/终端输出会显示"三因子/二因子"标识）。

v7 的 `--backfill` 可一次性补齐 60 天份额历史，能显著缩短退化时段。

### 交叉验证逻辑（关键）

- 单只ETF触发高确信 → 可能是偶发事件
- **多只宽基ETF同时触发高确信** → 几乎不可能是巧合，信号极强
- 特别关注：**4只沪深300ETF同时触发** → 国家队确定性入场

## ⚠️ 模型局限性

1. **尾盘细节缺失**：日线数据只能看全天总量，无法精确区分早盘/中盘/尾盘。汇金最典型的尾盘集中放量被用全天倍量近似判断（f4 固定 35 分）。

2. **减持信号更难**：汇金减持通常分散、有序、隐蔽，且可通过一级市场赎回（份额减少但成交量不大）。当前模型对减持识别远不如增持——份额因子映射有意的申购偏置加剧了这一点。

3. **份额数据时效性**：akshare 交易所数据盘后约19:00更新，盘中运行将自动使用最近可用日。

4. **二因子/三因子不可比**：份额缺失日退化为二因子（70/30），与三因子（50/20/30）的 cp 不能直接比较大小，见"二因子退化"一节。

5. **申购者身份不可区分**：份额增长无法区分国家队 vs 普通投资者/套利盘。1% 级份额变动（510300 上约 10 亿元）日常套利流完全可能触及，牛市普涨期份额普遍增加——模型在牛市中存在系统性误报倾向。

6. **事件验证样本有限**：全部阈值均为手工设定。已用 2026-07 汇金增持事件初步对照验证：模型回溯在 **2026-07-13/17/20** 给出的多 ETF 同步 🔴 信号，与公开报道的 7/13-17 国家队大规模入场（当周股票 ETF 净申购 2036 亿元创历史纪录、7/17 单日 759 亿元历史第三）完全吻合；信号同时覆盖沪深300/中证500/中证1000（510300、510500、512100 等），与报道的"大-中-小盘三层结构"一致。但目前仅一个事件窗口，建议持续用后续公开事件扩展验证。

## 🔬 v7 数据源详情

### 量能/方向因子（未变）

- API：`web.ifzq.gtimg.cn/appstock/app/fqkline/get`
- 数据源：腾讯财经（免费，可回溯60天）
- 返回：日线OHLC + 成交量

### 份额因子（v7 新）

- **上交所ETF**：`akshare.fund_etf_scale_sse(date)`
  - 输入：日期 YYYYMMDD
  - 输出：全市场上交所ETF份额（约800+只）
  - 历史回溯：✅ 支持（可查任意历史日期）
- **深交所ETF**：`akshare.fund_scale_daily_szse(start, end)`
- 输入：起始日期、结束日期 YYYYMMDD
  - 输出：全市场深交所ETF份额
  - 历史回溯：✅ 支持（日期范围查询）

### 份额数据更新时间

- 上交所/深交所：交易日后 **19:00** 左右更新
- 脚本自动回退到最近可用日（若当日数据未发布）
