# ETF三因子模型详解

## 1 概述

国家队（中央汇金）增持 ETF 有两条独立路径：

| 路径         | 市场      | 痕迹                   |
| ------------ | --------- | ---------------------- |
| 二级市场买入 | 交易所    | 成交量异常放大         |
| 一级市场申购 | ETF发行方 | 总份额增加（无成交量） |

只靠成交量（量能因子）判断，会漏掉一级市场路径的信号。

**三因子模型**：信号分 = 量能分 × 50% + 方向分 × 20% + 份额分 × 30%

> **模型定位**：输出为 0~100 的启发式**信号分**，不是校准过的统计概率——它表示增持线索的相对强度（历史事件日普遍 ≥70，平静期通常 <40），但同一分数在不同市场环境下对应的真实增持可能性并不同。数据在 T 日收盘后才完整、份额约 19:00 发布，信号天然滞后一天；本模型适合**盘后确认与持续跟踪**（识别持续增持期），而非当天抢入场点。

---

## 2 因子一：量能分（权重 50%）

### 2.1 原理

汇金单次增持几十到上百亿元，每次大操作都会在成交量图表上留下显著痕迹。

### 2.2 计算

1. 取过去 20 个交易日的每日成交量
2. 计算 20 日平均成交量（ma20）
3. 当日成交量 ÷ ma20 = **倍量（volume_ratio）**

### 2.3 倍量 → 量能分映射

| 倍量范围 | 量能分 |
| -------- | ------ |
| <0.5x    | 0~5    |
| 0.5~1.0x | 5~17   |
| 1.0~1.3x | 17~35  |
| 1.3~1.5x | 35~55  |
| 1.5~2.0x | 55~80  |
| 2.0~3.0x | 80~95  |
| 3.0~5.0x | 95~98  |
| >5.0x    | 98~100 |

### 2.4 设计思路

- 基准用 20 日（约一个月），对近期资金行为最敏感
- 不对称映射：放量段映射更陡（敏感），缩量段映射平缓

## 3 因子二：方向分（权重 20%）

### 3.1 原理

汇金操作目的不是赚钱，而是**护盘**。放量时的市场环境决定该放量是不是"护盘行为"。

### 3.2 四个维度（权重 40% / 30% / 20% / 10%）

> 实现说明：`dprob()` 的 f1~f4 按 40/30/20/10 加权后，再乘普涨折扣（见 3.3）。下表中的"5日大盘"指沪深300近5个交易日涨跌幅（负值=下跌趋势）。

#### 3.2.1 维度一：当日行情 + 大盘环境（40%，f1）

逆市护盘的实现定义为 **ETF当日上涨 + 大盘近5日处于跌势**（而非"当日大盘下跌"）。按代码顺序判定，先命中先生效：

| 条件（依次判定）                             | f1  |
| -------------------------------------------- | --- |
| ETF涨>0.3% 且 5日大盘<-1%                    | 95  |
| ETF涨>0 且 5日大盘<-0.5%                     | 85  |
| ETF涨>0 且 5日大盘<0                         | 70  |
| 涨跌绝对值≤0.15% 且 5日大盘<-1%              | 80  |
| 涨跌绝对值≤0.3% 且 5日大盘<-0.5%             | 65  |
| ETF涨>1% 且 倍量>1.5x（放量上涨）            | 45  |
| ETF涨>0.5% 且 倍量>1.3x                      | 50  |
| ETF涨>0（普涨）                              | 40  |
| ETF跌<-1.5% 且 倍量>2x（放量下跌，恐慌出逃） | 8   |
| ETF跌<-0.5% 且 倍量>1.5x                     | 15  |
| 其余                                         | 25  |

> 由于按顺序先命中先生效，表中"涨跌绝对值≤..."两档实际只在**微跌或平盘**时可达（微涨情形已被上方 `ETF涨>0` 各档截获）；上涨各档与下跌各档互斥，不受顺序影响。阅读时应把条件列理解为"实际有效域"，而非互斥完备的分区。

#### 3.2.2 维度二：ETF vs 沪深300 近5日超额（30%，f2）

超额按**近5个交易日**计算（gap = ETF 5日涨跌 − 沪深300 5日涨跌）：

| 5日超额            | f2  |
| ------------------ | --- |
| >3%                | 95  |
| >2%                | 85  |
| >1.2%              | 75  |
| >0.6%              | 60  |
| >0.2%              | 50  |
| -0.2~0.2%          | 40  |
| -0.6~-0.2%         | 30  |
| ≤-0.6%（跑输大盘） | 15  |

#### 3.2.3 维度三：前5日大盘走势（20%，f3）

| 5日大盘         | f3                 |
| --------------- | ------------------ |
| <-4%            | 95（护盘需求极强） |
| -4~-3%          | 90                 |
| -3~-2%          | 80                 |
| -2~-1%          | 70                 |
| -1~-0.5%        | 55                 |
| -0.5~0%         | 45                 |
| 0~1%            | 35                 |
| 1~3%            | 20                 |
| >3%（需求极弱） | 10                 |

#### 3.2.4 维度四：尾盘行为（10%，f4）

- 目前简化处理为固定 **35 分**（日线数据无法精确区分尾盘），对方向分的恒定贡献为 35×10% = 3.5 分
- 理想情况下应分析尾盘拉升幅度

### 3.3 普涨折扣

当大盘**当日**涨幅较大时，整体方向分打折（此折扣统一处理普涨降级，f1 内部不再单独扣减）。档位边界与代码一致（按涨幅从高到低逐级判定）：

| 大盘当日涨幅 | 折扣  |
| ------------ | ----- |
| >2.0%        | ×0.60 |
| 1.5~2.0%     | ×0.70 |
| 1.0~1.5%     | ×0.80 |
| 0.5~1.0%     | ×0.90 |

## 4 因子三：份额分（权重 30%）

数据源：akshare 交易所官方接口，支持完整历史回溯。

### 4.1 原理

通过一级市场申购 ETF 时，不会产生二级市场成交量，但会直接增加 ETF 总份额。

### 4.2 计算

1. 获取目标日与**前一个交易日**的基金总份额（只需两日）
2. 日份额变化 = 当日份额 - 前日份额
3. 份额变动比 = 日份额变化 ÷ 前日份额 × 100%

> **每只 ETF 使用其自身的份额变化**（`analyze_all` 按代码独立取值）。2026-08 修复过一处历史 bug：份额因子曾误用 `shares_map` 中第一个代码（510300）的份额变化，导致所有 ETF 的份额分相同、中小盘份额信号被掩盖——事件锚点测试（tests/）发现并验证了该修复。

### 4.3 份额变动比 → 份额分

映射为**连续分段函数**，0% 无变动处为近中性 15 分：

| 份额变动比 | 份额分 | 解读                       |
| ---------- | ------ | -------------------------- |
| >10%       | 95     | 大规模申购，明确国家队入场 |
| 5~10%      | 80~95  | 较大规模申购               |
| 3~5%       | 65~80  | 中等申购                   |
| 1~3%       | 45~65  | 小幅申购                   |
| 0~1%       | 15~45  | 常规申购/正常波动          |
| -1~0%      | 10~15  | 轻微赎回                   |
| -5~-1%     | 5~10   | 赎回                       |
| <-5%       | 0~5    | 大幅赎回（疑似减持）       |

> 映射以申购方向为主：同等幅度的赎回得分显著低于申购（1% 申购 45 分 vs 1% 赎回 10 分）。这是有意的偏置——模型只识别增持，减持识别见第 6 章。

### 4.4 实际案例

以华泰柏瑞沪深300ETF（510300）为例。截至 2026-08-26：总份额约 **238.5 亿份**，收盘价约 4.68 元：

| 份额变动比 | 对应份额    | 对应资金   |
| ---------- | ----------- | ---------- |
| 1%         | 约 2.4 亿份 | 约 11 亿元 |
| 2%         | 约 4.8 亿份 | 约 22 亿元 |
| 5%         | 约 11.9 亿份 | 约 56 亿元 |
| 10%        | 约 23.9 亿份 | 约 112 亿元 |

> **份额基数会随时间漂移**：同一只 ETF 的总份额并非常量——510300 在 2026 年 5 月尚有约 333 亿份，8 月已降至约 238 亿份（中间穿插了国家队级别的申赎）。这意味着同一个"变动比阈值"对应的绝对资金规模会随基数缩放：基数小时小资金也能触发高变动比（见局限 6 跨规模不可比），且历史案例的金额换算不能直接套用到当下。

汇金单次增持通常在几十到上百亿元。按当前基数（总市值约 1120 亿元）换算：**10 亿元 ≈ 0.9%、50 亿元 ≈ 4.5%、百亿元 ≈ 9%** 的份额变动比；仅当单日净买入达到数百亿元级（如 2026-07 纪录周）才会出现 >10% 的极端变动。模型实际捕捉到的多数 🔴 信号日对应的并非当日百分比爆表，而是**多只 ETF 同步的中高变动 + 数日累计**——这正是交叉验证逻辑（5.3）存在的意义。

## 5 信号分与信号解读

```text
信号分 = 量能分 × 50% + 方向分 × 20% + 份额分 × 30%
```

### 5.1 信号分级（三级）

| 信号分   | 级别        | 解释                   |
| -------- | ----------- | ---------------------- |
| ≥70 分   | 🔴 高确信   | 国家队大概率正在增持   |
| 50~70 分 | 🟡 中等确信 | 值得关注，等待更多确认 |
| <50 分   | ⚪ 无信号   | 正常交易               |

### 5.2 二因子退化（份额数据缺失时）

份额数据不可用的日期（如回溯前的历史日、份额盘后 19:00 未发布），信号分退化为二因子：

```text
信号分 = 量能分 × 70% + 方向分 × 30%
```

二因子与三因子的信号分不可直接比较：三因子把量能权重降至 50%、份额零变动时基线注入约 4.5 分（份额下降时更低）；二因子则把量能权重提到 70%。结果是**高量能日三因子得分可能低于二因子**（量能权重削减超过份额注入），同一天在不同数据状态下算出的分数不能直接比大小。跨模式比较历史信号时应加标注（报告/终端输出会显示"三因子/二因子"标识）。

`--backfill` 可一次性补齐 60 天份额历史，能显著缩短退化时段。

### 5.3 交叉验证逻辑

- 单只 ETF 触发高确信 → 可能是偶发事件
- **多只宽基 ETF 同时触发高确信** → 几乎不可能是巧合，信号极强
- 特别关注：**4 只沪深300ETF 同时触发** → 国家队确定性入场

## 6 模型局限性

1. **尾盘细节缺失**：日线数据只能看全天总量，无法精确区分早盘/中盘/尾盘。汇金最典型的尾盘集中放量被用全天倍量近似判断（f4 固定 35 分）。

2. **减持信号更难**：汇金减持通常分散、有序、隐蔽，且可通过一级市场赎回（份额减少但成交量不大）。当前模型对减持识别远不如增持——份额因子映射有意的申购偏置加剧了这一点。

3. **份额数据时效性**：akshare 交易所数据盘后约 19:00 更新。盘中运行当日份额不可用，今日信号退化为二因子（见 5.2）；份额按实际数据日入库，盘中取到的是最近发布日的值。

4. **二因子/三因子不可比**：份额缺失日退化为二因子（70/30），与三因子（50/20/30）算出的分数不能直接比较大小，见 5.2。

5. **申购者身份不可区分**：份额增长无法区分国家队 vs 普通投资者/套利盘。1% 级份额变动（510300 上约 10 亿元）日常套利流完全可能触及，牛市普涨期份额普遍增加——模型在牛市中存在系统性误报倾向（2026-08 锚点扩容后已有实证：抱团期平静周负锚点 neg-2021-04 中，单只 ETF 一度达到 72 分的近似误报水平）。

6. **份额因子跨规模不可比**：份额变动比没有按 ETF 规模归一化——同样 ±1%，238 亿份的 510300 对应约 10 亿元，而 84 亿份的 510330 只需约 1 亿元即可触发，小规模 ETF 天然更容易得到高份额分。因此各 ETF 的份额分/信号分**不宜横向排序比较强弱**，跨标的比较应结合绝对申赎额（份额日变 delta 亿份 × 价格）。候选改进为金额分档归一化，待锚点样本积累后再评估。

7. **ma20 基准自污染**：量能基准包含汇金自己此前的放量日——连续多日增持时（如 2026-07），前期放量抬高 20 日均量，后续同等买入的倍量被压低，**增持中后段信号会系统性减弱**；对首日引爆型操作无影响。候选改进为换用中位数等稳健基准。

8. **事件验证样本仍有限**：全部阈值均为手工设定。截至 2026-08 已用 8 个锚点窗口回归验证（见 `tests/events.json`）：4 个正锚点（2023-10 首次公告买入、2024-02 扩大范围至中小盘、2025-04 盘中公告、2026-07 单周净申购 2036 亿创纪录）全部按期望触发多 ETF 同步 🔴，公告日精确命中；4 个数据驱动挑选的平静周负锚点均无多 ETF 同步误报（但 neg-2021-04 出现单只 72 分的近似误报，见局限 5）。权重敏感性扫描显示当前 (50/20/30) 位于两类约束的平衡点附近。样本量级仍是"数个事件窗"而非统计充分，后续公开事件应继续纳入回归验证后再考虑调整任何参数。

## 7 数据源详情

### 7.1 量能/方向因子

- API：`web.ifzq.gtimg.cn/appstock/app/fqkline/get`
- 数据源：腾讯财经（免费，可回溯 60 天）
- 返回：日线 OHLC + 成交量

### 7.2 份额因子

- 上交所 ETF：`akshare.fund_etf_scale_sse(date)`
  - 输入：日期 YYYYMMDD
  - 输出：全市场上交所 ETF 份额（约 800+ 只）
  - 历史回溯：支持（可查任意历史日期）
- 深交所 ETF：`akshare.fund_scale_daily_szse(start, end)`
  - 输入：起始日期、结束日期 YYYYMMDD
  - 输出：全市场深交所 ETF 份额
  - 历史回溯：支持（日期范围查询）

### 7.3 份额数据更新时间

- 上交所/深交所：交易日后 **19:00** 左右更新
- 当日数据未发布时，今日信号退化为二因子（见 5.2）；份额按实际数据日入库
